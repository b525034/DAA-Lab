### Algorithm: Find a Pair with Sum `x`

Input: Two sets `S1` and `S2`, each containing `n` elements, and a number `x`.

Output: Whether there exists an element from `S1` and an element from `S2` whose sum is `x`.

1. Start
2. Read `n`, the size of the two sets.
3. Read the elements of `S1`.
4. Read the elements of `S2`.
5. Sort `S2` in ascending order.
6. For each element `S1[i]` in `S1`:

    Calculate:
     `required = x - S1[i]`
    Perform binary search for `required` in `S2`.
    If `required` is found in `S2`:

      Display the pair `S1[i]` and `required`.
      Return YES and stop.
7. If the loop finishes without finding a pair, return NO.
8. Stop

### Binary Search Algorithm

1. Set `low = 0` and `high = n - 1`.
2. While `low <= high`:

   Calculate `mid = (low + high) / 2`.
   If `S2[mid] == key`, return 1 (found).
   If `S2[mid] < key`, set `low = mid + 1`.
   Otherwise, set `high = mid - 1`.
3. If the loop ends, return **0 (not found)**.

### Complexity

Sorting `S2`: O(n log n)
`n` binary searches: O(n log n)
Overall: O(n log n).
